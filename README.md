# End-to-End IMDB Data Analysis Project

## 1. Project Overview
This project analyzes a dataset of 100 top-rated movies to identify the relationship between 
budgets, genres, and audience demographics.

## 2. Key Findings & Insights
- **Profitability:** Action and Animation genres are the most profitable, with *Star Wars: Episode VII* leading the dataset.
- **Demographics:** Female audiences tend to give higher ratings to the 'Animation' and 'Mystery' genres compared to male audiences.
- **ROI vs Budget:** High budgets do not always guarantee high IMDb ratings. Moderate-budget films often have higher ROI.

## 3. Actionable Insights
- **Investment Strategy:** Investors should focus on high-concept Animation films which show high cross-demographic appeal.
- **Marketing:** Use demographic-specific targeting (e.g., targeting female audiences for Mystery/Drama releases) to maximize ratings.
